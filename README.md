Aplikasi Peminjaman Barang
Selamat datang di repositori Aplikasi Peminjaman Barang! ✨

Aplikasi ini merupakan solusi Android berbasis Java yang dikembangkan untuk mempermudah manajemen proses peminjaman barang dalam lingkungan organisasi, perpustakaan, atau inventaris perusahaan. Studi kasus yang digunakan adalah UIN Syarif Hidayatullah, dan aplikasi ini dibuat sebagai prototype fitur tambahan dalam Academic Information System UIN.

Fitur Utama
1. Peminjaman Barang

Pencatatan Transaksi:
Pengguna dapat melakukan peminjaman barang dengan mudah melalui antarmuka yang intuitif. Setiap transaksi mencatat informasi penting seperti:

-Nama dan identitas peminjam
-Tanggal peminjaman
-Jumlah dan jenis barang yang dipinjam
-Tujuan peminjaman

2. Pengembalian Barang dan Pengelolaan Denda
-Proses Pengembalian Terintegrasi:
  Aplikasi memudahkan pengguna dalam mengembalikan barang dengan mencatat tanggal dan waktu pengembalian. Setiap proses        pengembalian langsung terhubung dengan data transaksi peminjaman.

 -Perhitungan Denda Otomatis:
  Jika terjadi keterlambatan dalam pengembalian, sistem akan menghitung denda secara otomatis berdasarkan durasi           
  keterlambatan. Informasi denda ditampilkan secara transparan kepada pengguna untuk proses penyelesaian pembayaran.

4. Notifikasi dan Pengingat
  -Notifikasi Otomatis:
   Sistem mengirimkan notifikasi kepada pengguna terkait:
   Konfirmasi peminjaman barang
   Pengingat batas waktu pengembalian
   Pemberitahuan mengenai denda apabila terjadi keterlambatan
5. Riwayat Transaksi
  -Penyimpanan Historis:
   Setiap transaksi peminjaman dan pengembalian barang disimpan dalam database. Hal ini memudahkan:
   > Pencarian data transaksi untuk keperluan audit
   > Analisis penggunaan barang dari waktu ke waktu
   > Pelaporan dan evaluasi kinerja peminjaman barang


Teknologi yang Digunakan
Bahasa Pemrograman: Java
Platform: Android
IDE: Android Studio
Database: Firebase dan Supabase
